# Security & Vulnerability Disclosure Policy

## Supported Product
Car FM Transmitter Model SS5437ARGI(G45)
Defined support period: 2 years until 08/2028.
This is a constrained device under ETSI EN 303 645 V2.1.1 Clauses 5.3-14 and 5.3-15; it does not support firmware or software security updates.

## No Universal Default Password
Bluetooth pairing uses SSP user confirmation or random per-session code (ETSI EN 303 645 Clause 5.2-1).

## Reporting a Vulnerability
Email: security@gxyelectronics.com
We acknowledge receipt within 5 working days in accordance with ISO/IEC 29147:2018.
During the support period, issues are handled via published advisories, workaround guidance, or successor-model recommendation.

## After Support Period
After 08/2028, the manufacturer is no longer obligated to provide security advisories or replacements for this model.
