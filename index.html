Security & Vulnerability Disclosure Policy

This page provides security information and vulnerability reporting guidance for products manufactured by Shenzhen GXY Electronic Co., Ltd.

Product Security Statement

The product Car FM Transmitter Model SS5437ARGI(G45) is a constrained device under ETSI EN 303 645 V2.1.1 (2020-06), Clauses 5.3-14 and 5.3-15. It does not support firmware or software security updates.

This product does not use universal default passwords. Bluetooth pairing is protected by user confirmation or random per-session codes in accordance with ETSI EN 303 645 Clause 5.2-1.

During the defined support period (until 08/2028), security vulnerabilities will be handled via:

  • Published security advisories
  • Workaround or configuration guidance
  • Successor-model or replacement recommendations

Hardware replacement support is available via the point of purchase or authorised service channels.

After the support period ends, the manufacturer is no longer obligated to provide security advisories or replacements related to this product.

How to Report a Security Issue

If you believe you have found a security vulnerability in our product, please contact us at:

Email: wangweian@gxykit.com

We ask that you:

  • Provide a clear description of the issue
  • Include steps to reproduce (if applicable)
  • Avoid testing against third-party infrastructure or end users

In accordance with ISO/IEC 29147:2018, we will:

  • Acknowledge receipt of your report within 5 working days
  • Provide regular status updates until the issue is resolved or mitigated
  • Credit researchers (unless anonymity is requested)

Defined Support Period

The defined support period for this product is 2 years, ending on 08/2028. This information is current as of 12/08/2026.
